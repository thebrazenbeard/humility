# META ↔ HUMILITY: optional, falsifiable interface V1

Current `thebrazenbeard/meta` researches feedback-driven selection of **prewritten cognitive methods**. Current `thebrazenbeard/humility` researches calibration, evidence dependence, uncertainty, and justified revision. They are complementary independent projects, not an installed coupled system.

## Proposed evaluable handshake

1. META proposes a method before outcomes are exposed: a frozen single-read baseline, blind-observer counterread, or another preauthorized method. Freeze method ID and evaluation protocol.
2. HUMILITY records the method's candidate interpretations, verbatim evidence quotes, modality drift, and unstated assumptions. It never automatically declares truth, author intent, or safety.
3. An independently controlled evaluator retains outcome labels and scores later response fidelity: original referent, role, scope, polarity, speech-act modality, correction handling and counter-reading. Compare with frozen, randomized and always-cautious controls.
4. META may select among already permitted methods using legitimate observed feedback. This does not invent a new cognitive method, prove introspection, or change model weights. Test shifted and unfamiliar domains.

Falsifiers: intentional ambiguity falsely called a mistake; clear language forced into spurious alternatives; abstract thought promoted to intent; forged quoted evidence; duplicated evidence counted as independent; private author-intent leakage; false claims of an independent review or invocation; improved training cases but failure after distribution shift.

No integration grants tool permissions, installation, model training, hosted runtime interception, private memory writes, publication, or production action. Both repositories remain independently usable, and any integration requires separately verified execution.
